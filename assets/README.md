# Assets Directory

- `scenes/` contains local scene backgrounds and scene-card images.
- `references/` contains local drawing reference materials.
- `placeholders/` contains the loading and error images used by the fallback system.

The main local visual assets were generated and prepared specifically for Creative Drawing App. See [../ASSETS.md](../ASSETS.md) for provenance notes and [../assets-to-replace.md](../assets-to-replace.md) for non-core remote assets that still need license-safe replacements.

`image-inventory.json` is a historical audit snapshot, while `replacement-slots.json` records the current state of the original priority localization slots.
